# Learning Spanish with Penguin — build contract

Every agent working on this repo reads this file first. It fixes the file layout, the data schemas and the
CSS/JS interfaces so pieces built in parallel fit together. **Only write the files your brief assigns to you.
Do not `git commit`, do not push.**

## Goal

A local, click-through Spanish course for an English speaker who understands speech well once they can *read*
what is being said. Trip to Mexico starts **2026-10-30**, so: **Mexican Spanish** everywhere (ustedes, never
vosotros; carro, celular, jugo, boleto, camión (bus in CDMX), ¿mande?, ahorita, etc.; Spain-only forms only as notes).

The learner must be able to:

1. **Learn** the ~3000 most frequent words (lemmas) plus high-frequency **word sequences / chunks**.
2. **Drill** words and chunks (spaced repetition): read, listen, type, recognise.
3. **Hear** them at careful speed *and* in natural fast speech, with **"how it actually sounds"** respellings
   (e.g. *para* → *pa'*, *¿qué onda?*, *todo* → *to'o*, *lo que es* → *lo kes*), like "by the way" → "badaway".
4. Learn and drill **grammar** (gender o/a, agreement, ser/estar, conjugation, …) as well as vocabulary.
5. **Respond to prompts** in Spanish (typed), graded *leniently*: typos and accents are forgiven, grammar slips
   are pointed out kindly but do not fail the answer. Meaning/recall is what is scored.
6. **Write a goal story**: a story goal in English with beats, the learner writes it in Spanish, gets feedback.

Feedback is delivered by **a cartoon penguin wearing a sombrero** (the mascot). Light, Mexican-inspired palette.

## Stack (mirrors the user's ChessPrep app)

- `server/app.py` — **FastAPI**, serves `web/` and a small API; progress in **SQLite** (`data/progress.db`,
  git-ignored). Port **8300**. `start.bat` starts it and opens the browser.
- `web/` — **plain HTML/CSS/JS, no build step, no framework, no CDN**. Must also work with the server absent
  (opened from GitHub Pages or `file://`): course data is loaded as a `<script>` (`web/data/course.js`), and
  progress falls back to `localStorage`.
- `content/*.json` — the authored course content (source of truth).
- `scripts/build_course.py` — validates `content/*.json` and writes `web/data/course.js`
  (`window.COURSE = {...}`) including the lesson plan.
- Audio: browser **Web Speech API** (`speechSynthesis`), preferring an `es-MX` voice; optional speech
  recognition (`webkitSpeechRecognition`, `es-MX`) for "say it". No audio files.
- Optional AI coach: `POST /api/coach` uses the Anthropic API **only if `ANTHROPIC_API_KEY` is set**;
  otherwise the app uses its built-in rule-based grader. The app must be fully usable without it.

## Shared vocab conventions

- `id`: `"v_" + lemma` with accents removed, spaces → `_`, lowercase. Homographs: suffix `_2` etc. (`v_como`,
  `v_como_2`). Chunks use `"c_"`, grammar units `"g_"`, prompts `"p_"`, stories `"st_"`, sound rules `"s_"`.
- `rank`: your best estimate of the lemma's position in a **general Spanish frequency list of lemmas**
  (spoken-weighted; think Davies' *Frequency Dictionary of Spanish* / subtitle corpora). 1 = most frequent.
  Integers, roughly 1–5000. Used to interleave the three vocab files, so be honest, not tidy.
- `tier`: 1 = rank 1–500, 2 = 501–1000, 3 = 1001–1500, 4 = 1501–2000, 5 = 2001–2500, 6 = 2501+.
- `topic`: one of
  `people, family, body, health, food, drink, home, city, places, travel, transport, money, shopping, time,
  weather, nature, animals, work, school, emotions, communication, clothing, numbers, colors, description,
  actions, abstract, leisure, technology, function, courtesy, directions, hotel, restaurant, emergency`.
- Examples: short, natural, Mexican-flavoured, mostly present tense and high-frequency words, ≤ 10 words.
- `natural` (optional everywhere): array of **"how it sounds in fast speech" respellings**, written so that a
  Spanish TTS voice reading the respelling sounds roughly like the reduced form (e.g. `"pa' que"`,
  `"to'o bien"`, `"ps"`). Leave out when the word is not reduced in practice.

## Schemas

### Vocab entry (`content/vocab_*.json`)

```json
{
  "id": "v_casa",
  "es": "casa",
  "en": "house, home",
  "pos": "noun",                      // noun|verb|adj|adv|pron|prep|conj|det|num|interj
  "rank": 120,
  "tier": 1,
  "topic": "home",
  "gender": "f",                      // nouns: "m" | "f" | "mf" (el/la estudiante); else omit
  "article": "la",                    // nouns: "el" | "la" | "el/la"; "el" for el agua (feminine, note it)
  "plural": "casas",                  // nouns (and adjectives' masc. plural); omit if invariable/none
  "fem": null,                        // adjectives: feminine singular ("bonita"); invariable adj: same as es
  "conj": {                           // verbs only. Order: yo, tú, él/ella/usted, nosotros, ellos/ellas/ustedes
    "pres": ["hablo","hablas","habla","hablamos","hablan"],
    "pret": ["hablé","hablaste","habló","hablamos","hablaron"],
    "imp":  ["hablaba","hablabas","hablaba","hablábamos","hablaban"],
    "fut":  ["hablaré","hablarás","hablará","hablaremos","hablarán"],
    "subj": ["hable","hables","hable","hablemos","hablen"],
    "cmd":  {"tu": "habla", "usted": "hable"},
    "ger": "hablando",
    "part": "hablado",
    "irregular": false,
    "reflexive": false                // true for lemmas like "llamarse" (forms then include "me llamo" etc.? NO:
                                      // give bare forms "llamo"; the app adds pronouns)
  },
  "ex_es": "Mi casa es tu casa.",
  "ex_en": "My house is your house.",
  "note": "optional learner tip: false friend, gender exception, Mexico usage",
  "natural": ["optional fast-speech respellings"]
}
```

```json
  "sound_rules": ["s_apocope"],       // ids from sounds.json that explain the reduction

  "note": "optional: register, Mexico usage"

```

### Connected-speech rule (`content/sounds.json`)

```json
{
  "id": "s_sinalefa",
  "name": "Vowel linking (sinalefa)",
  "summary": "one line",
  "explain": "3-6 sentences, plain English, how to hear it",
  "mexico": "how it shows up in Mexican speech specifically",
  "examples": [
    {"written": "lo que es", "sounds": "lo kes", "en": "what it is", "slow": "lo que es", "fast": "lo kes"}
  ],
  "drills": [
    {"type": "hear_pick",   "say": "lo kes", "options": ["lo que es", "lo que hay", "el queso"], "answer": "lo que es"},
    {"type": "hear_type",   "say": "pa' que", "answer": "para que"}
  ]
}
```

`say` is the text fed to the TTS (may be a respelling); `answer` is the standard written form.

### Grammar unit (`content/grammar.json`)

```json
{
  "id": "g_gender",
  "title": "Masculine & feminine nouns (o / a)",
  "order": 1,                         // course order of grammar units
  "tier": 1,
  "summary": "one line",
  "explain": "short markdown (bold, lists, tables allowed) — teach it, with Mexican examples",
  "rules": [
    {"rule": "Nouns ending in -o are usually masculine.", "examples": ["el libro", "el vaso"],
     "exceptions": ["la mano", "la foto", "la radio"]}
  ],
  "drills": [
    {"type": "choice",    "q": "___ mesa", "options": ["el", "la"], "answer": "la", "why": "mesa ends in -a → feminine"},
    {"type": "fill",      "q": "La casa es ___ (bonito).", "answer": "bonita", "why": "adjective agrees with casa (f)"},
    {"type": "transform", "q": "el gato negro → plural", "answer": "los gatos negros", "why": "..."},
    {"type": "translate", "q": "the red car", "answer": "el carro rojo", "alts": ["el coche rojo"], "why": "..."}
  ]
}
```

Each unit ≥ 12 drills, mixing types. `answer` + `alts` are all accepted answers.

### Reading story (`content/readings.json`)

Read-and-explain stories: the learner reads one Spanish sentence at a time, types what it means in English in
their own words, then reveals the translation. **Not graded** — the learner self-marks got it / partly / missed.

```json
{
  "id": "rd_el_taxi",
  "tier": 1,
  "after_grammar": "g_present_ar",    // unlock after this grammar unit (or null)
  "title": "El taxi",
  "title_en": "The taxi",
  "topic": "transport",
  "level_note": "present tense, ~70 words",
  "sentences": [
    {
      "es": "Matt llega al aeropuerto a las once de la noche.",
      "en": "Matt arrives at the airport at eleven at night.",
      "gist": "He lands late at night.",          // the big idea, in plain words
      "words": [{"es": "llega", "en": "arrives (llegar)"}],   // 1-4 glosses for words a learner might miss
      "natural": "Matt llegal aeropuerto a lasonce de la noche."   // optional: how it sounds fast (TTS-readable)
    }
  ]
}
```

### Conversation API (`server/chat.py`, mounted by `server/app.py`)

- `GET /api/chat/status` → `{"available": bool, "backend": "local" | "claude" | null, "model": "…", "note": "…"}`.
  `local` = small open-source model on this computer (works offline); `claude` = Anthropic API if
  `ANTHROPIC_API_KEY` is set and the user picks it (or no local model is installed).
- `POST /api/chat` with
  `{"topic_id": "ch_playa", "level": 1, "history": [{"role": "bot" | "user", "text": "…"}], "backend": "local" | "claude" | null}`
  → `{"reply_es": "…", "reply_en": "…", "correction": {"original": "…", "fixed": "…", "why_en": "…"} | null,
     "suggestions": ["2–3 short things the learner could say next, in Spanish"], "backend": "local", "ms": 1234}`.
  `reply_es` is ONLY Spanish, 1–3 short sentences at the learner's level, ending with a question that keeps the
  topic going. `correction` gently fixes the learner's LAST message (null if it was fine or not Spanish).
  If the learner writes in English, reply in simple Spanish anyway (maybe recasting what they meant).
- Errors → HTTP 503 `{"error": "…", "setup": "how to install the local model"}`; the page shows that nicely.

## Lesson plan (built by `scripts/build_course.py`, consumed by the app)

`window.COURSE = { meta, vocab, chunks, sounds, grammar, prompts, stories, units }` where `vocab` etc. are the
merged arrays (deduplicated by `id`, sorted by `rank`) and

```json
"units": [
  {"id": "u01", "title": "Survival basics", "tier": 1,
   "lessons": [
     {"id": "u01l01", "title": "Hello & please",
      "steps": [
        {"type": "learn",   "items": ["v_hola", "c_por_favor", "..."]},   // new words + chunks (≈8–12)
        {"type": "sounds",  "rule": "s_sinalefa"},                       // optional
        {"type": "grammar", "unit": "g_gender"},                          // optional
        {"type": "drill",   "items": ["…ids just learned…"]},
        {"type": "build",   "items": ["…ids…"]},                         // sentence building from example sentences
        {"type": "prompt",  "id": "p_greet"},                            // optional
        {"type": "story",   "id": "st_first_night"}                      // optional, end of unit
      ]}
   ]}
]
```

Front-load what a traveller needs (greetings, numbers, ordering, directions, hotel, transport) while still
following frequency.

## Grading philosophy (engine)

Scored on recall of meaning, not perfection:

- Accents/ñ/¿¡/punctuation/case differences → **correct**, with a soft note ("watch the accent: *está*").
- Small typos (edit distance ≤ 1 for words ≤ 5 letters, ≤ 2 for longer) → **correct**, typo noted.
- Right word, wrong grammatical form (o/a, el/la, un/una, plural -s, wrong verb person/tense — detected using
  the vocab lexicon: genders, `fem`, `plural`, `conj`) → **counts as remembered**, but flagged as a grammar
  slip with a one-line explanation ("*casa* is feminine → *la casa bonita*").
- Missing / wrong content words → those words are marked; the item is "close" or "miss" by the share of
  content words recalled.
- Three outcomes: `good` (all recalled, maybe slips), `close` (most recalled), `miss`. SRS rating derived from
  them, and the learner can override.
